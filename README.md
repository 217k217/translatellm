## 地理位置信息

本项目支持处理和翻译包含地理位置信息的文本内容。

### 功能特点

- **位置识别**：自动识别文本中的地理位置信息（国家、城市、地址等）
- - **多语言支持**：支持多种语言的地理位置名称翻译
  - - **准确性保证**：保持地理位置信息的准确性和一致性
    - - **格式保留**：翻译时保留原有的位置信息格式
     
      - ### 使用示例
     
      - ```python
        # 示例：翻译包含地理位置的文本
        text = "我来自中国北京，现在在上海工作。"
        translated = translate(text, target_lang="en")
        # 输出: "I'm from Beijing, China, and now work in Shanghai."
        ```

        ### 注意事项

        - 地理位置名称会根据目标语言的习惯进行翻译
        - - 某些专有地名可能保持原文不变
          - - 支持GPS坐标等格式化位置信息的处理
